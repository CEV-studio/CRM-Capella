# CRM v1.1 — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development ou superpowers:executing-plans. Les étapes utilisent des cases à cocher (`- [ ]`).

**Goal:** Ajouter au CRM Capella : champs CAR élec/gaz, nom/prénom séparés, corbeille récupérable, permissions par personne, et pièces jointes ACD/Facture sécurisées.

**Architecture:** Une migration SQL `0004` porte tous les changements de schéma + RLS + Storage. Les écrans Next.js (App Router, server actions) sont mis à jour derrière. La sécurité reste au niveau Postgres/RLS ; les fichiers vivent dans un bucket Supabase Storage privé, servis par URL signée après vérification serveur.

**Tech Stack:** Next.js 16 (App Router, RSC, server actions), Supabase (Postgres, Auth, RLS, Storage), TypeScript, Tailwind v4.

**Vérification (pas de runner JS) :** `npx tsc --noEmit`, `npx eslint src --max-warnings=0`, `npm run build`, les tests `supabase/tests/rls_isolation.sql` (exécutés sur un Postgres local jetable), et le navigateur via les scripts `scripts/*.mjs`. **Nettoyer les données de test après chaque vérif.**

  /** Nom affichable d'un contact, avec repli sur la raison sociale. */
  export function nomComplet(
    nom: string | null | undefined,
    prenom: string | null | undefined,
    fallback?: string | null,
  ): string {
    const complet = [prenom, nom].filter((v) => v && v.trim()).join(" ").trim();
    return complet || (fallback ?? "").trim() || "(sans nom)";
  }
